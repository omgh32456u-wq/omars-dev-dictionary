# Omar's Dev Dictionary

A bilingual (Arabic/English) programming dictionary and learning companion.

## Phase 1 — Foundation & UI
- React 19 + TypeScript + Vite
- Responsive dashboard, navigation, dictionary listing, term detail and categories
- Arabic RTL / English LTR language switch
- Light and dark themes
- Starter sample terms only; the full 250+ term content set is Phase 2

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

Phase 1 is a foundation preview. Search, saved terms, and theme/language state are currently session-only; persistence and the remaining learning features are scheduled for Phase 3.
